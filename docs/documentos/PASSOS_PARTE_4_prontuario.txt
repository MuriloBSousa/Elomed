CAPITULO 1 - O BUG DOS TOASTS (leia com calma: e o que voce notou)
--------------------------------------------------------------------------------

1.1 O QUE ACONTECE HOJE

  Os controllers gravam a mensagem na sessao:

      Session::flash('success', 'Paciente cadastrado com sucesso');
      Session::flash('error',   'Token de seguranca invalido');

  Cada view, SEPARADAMENTE, decide se mostra essa mensagem:

      <?php if (Session::hasFlash('success')): ?>
          <div class="alert alert-success"><?= e(Session::getFlash('success')) ?></div>
      <?php endif; ?>

  E ai esta o problema, em duas partes:

  PARTE A - O toasts.js nunca e chamado.
      O fim do public/Assets/js/toasts.js procura por mensagens assim:

          document.querySelectorAll('p[style*="color: red"]');
          document.querySelectorAll('p[style*="color: green"]');

      Ou seja: um <p> com style inline "color: red"/"color: green".
      Nenhuma view do projeto escreve isso - todas usam
      <div class="alert alert-danger/success">. Entao esse trecho do
      toasts.js NAO ENCONTRA NADA. Nunca. A showToast() so aparece quando o
      proprio JavaScript chama (por exemplo, a busca de CEP).

      Resultado: a mensagem do servidor fica parada na pagina, como uma faixa
      grande, e o aluno le "isto e um aviso, nao um toast".

  PARTE B - Em algumas telas a mensagem some de verdade.
      Session::getFlash() APAGA a mensagem da sessao ao ler
      (app/middleware/Session.php: getFlash chama remove).
      Nas views que NAO imprimem o flash (boa parte das telas de medico,
      enfermeiro, tecnico e painel), ninguem le e ninguem apaga - a proxima
      requisicao le e apaga, e o aluno nunca ve.

      E por isso que voce viu "as vezes a confirmacao nao vem". Nao e
      instabilidade: e uma tela com o bloco de alerta e outra sem.

  RESUMO DA CAUSA: existem DOIS lugares diferentes para mostrar mensagem
  (o <div class="alert"> de cada view e o showToast do JavaScript), e o
  JavaScript nunca conversa com o PHP. A solucao e deixar UM lugar so.

1.2 CORRECAO - PARTE 1: o PHP precisa ler o flash sem apagar

  >> COLE EM: app/middleware/Session.php - logo DEPOIS do metodo hasFlash(),
     e ainda DENTRO da classe Session (antes do fecha-chave da classe).

      /**
       * Le a mensagem de flash SEM remover da sessao.
       *
       * POR QUE EXISTE: o getFlash() apaga a mensagem quando le. O
       * renderizador de toasts precisa ler para montar o toast e so
       * depois apagar - se usasse o getFlash(), a sessao ja ficaria
       * limpa e ainda seria preciso outro metodo para apagar.
       */
      public static function peekFlash(string $key, $default = null) {
          return self::get('_flash_' . $key, $default);
      }

      /**
       * Remove a mensagem de flash SEM ler (usado depois de ja ter lido).
       */
      public static function forgetFlash(string $key): void {
          self::remove('_flash_' . $key);
      }

      /**
       * Devolve as mensagens de flash como uma lista pronta para o toasts.js.
       * Nao consome a sessao: quem consome e o metodo limparFlash().
       */
      public static function toastsFlash(): array {
          $fila = [];
          foreach (['success', 'error', 'warning', 'info'] as $chave) {
              $mensagem = self::peekFlash($chave);
              if (is_string($mensagem) && trim($mensagem) !== '') {
                  $fila[] = [
                      'tipo'     => $chave,
                      'mensagem' => $mensagem,
                  ];
              }
          }
          return $fila;
      }

      /**
       * Apaga as mensagens de flash (depois que o toast ja foi montado).
       */
      public static function limparFlash(): void {
          foreach (['success', 'error', 'warning', 'info'] as $chave) {
              self::forgetFlash($chave);
          }
      }

  FIM DO BLOCO

  >> COLE EM: app/helpers/flash_toasts.php - CRIE O ARQUIVO

      <?php
      // Nao precisa de require: o autoload (app/config/autoload.php) ja
      // carrega a classe Session. Este arquivo so define a funcao.
      /**
       * flash_toasts
       * Gera o <script> que chama showToast() para cada mensagem de sessao.
       *
       * Este e o UNICO lugar do projeto que converte mensagem de servidor
       * em toast. Chame-o uma vez por requisicao, DEPOIS do toasts.js.
       *
       * Por que as mensagens entram com atraso (300ms entre uma e outra):
       * quando duas mensagens sao disparadas no mesmo instante, a segunda
       * apagaria a primeira. O toasts.js antigo removia o toast anterior a
       * cada chamada; o novo empilha (capitulo 1.4).
       */
      function flash_toasts(): void {
          Session::start();

          $fila = Session::toastsFlash();
          if (!$fila) {
              return;
          }

          Session::limparFlash();

          // JSON_HEX_TAG/AMP/APOS/QUOT impedem que uma mensagem contendo
          // "</script>" feche o bloco e quebre a pagina. As mensagens do
          // projeto vem de $e->getMessage() e de erros de validacao, que
          // podem conter texto digitado pelo usuario.
          $json = json_encode(
              $fila,
              JSON_UNESCAPED_UNICODE | JSON_HEX_TAG | JSON_HEX_AMP
              | JSON_HEX_APOS | JSON_HEX_QUOT
          );

          echo '<script>(function(){'
             . 'var f=' . $json . ';'
             . 'function proximo(){'
             . '  if(typeof showToast!=="function"){return;}'
             . '  if(!f.length){return;}'
             . '  var m=f.shift();'
             . '  showToast(m.tipo,m.mensagem,3000);'
             . '  setTimeout(proximo,300);'
             . '}'
             . 'if(document.readyState==="loading"){'
             . '  document.addEventListener("DOMContentLoaded",proximo);'
             . '}else{proximo();}'
             . '})();</script>';
      }

2.4 POR QUE CADA COLUNA (leia, isto e o que a banca pergunta)

  fk_paciente  -> de QUEM e o prontuario. ON DELETE CASCADE: se o cadastro do
                  paciente for removido, o prontuario vai junto (nao sobra
                  historico orfao).
  fk_usuario   -> QUEM escreveu (o login). NOT NULL: todo lancamento tem autor.
                  ON DELETE RESTRICT: o usuario nao pode ser apagado Having
                  historico assinado por ele.
  fk_profissional -> o registro de profissional (numero de registro/CRM,
                  especialidade). NULL porque o admin pode registrar por um
                  medico. ON DELETE SET NULL: se o cadastro do profissional
                  cair, o texto medico continua la - e o que a lei pede.
  fk_agendamento  -> a consulta que originou o lancamento. NULL porque um
                  medico pode registrar algo fora da agenda (exame de
                  retorno). ON DELETE SET NULL pelo mesmo motivo do
                  profissional.
  secao         -> qual das 3 paginas o lancamento pertence. ENUM e nao
                  VARCHAR: o banco so aceita os 3 valores da lista, e o
                  dump da secao fica curto (1 byte em vez de 14).
                  >>> CUIDADO com a frase "o banco rejeita 'anamnes'": este
                  MySQL roda SEM STRICT_TRANS_TABLES no sql_mode. Testado:
                  um INSERT com secao='anamnes' NAO deu erro - o MySQL
                  gravou '' (vazio) e accept. Entao a validacao de verdade
                  esta no PHP, no metodo secoesValidas() do controller, e
                  nao no banco. Se um dia o banco ganhar o modo estrito, a
                  garantia passa a ser em dobro. Nao conte com o ENUM para
                  dispensar a validacao no controller.
  conteudo      -> o texto. TEXT e nao VARCHAR: uma evolucao de consulta
                  passa de 255 caracteres com facilidade.
  status        -> 'rascunho' (pode editar) ou 'finalizado' (imutavel).
                  Default 'finalizado': o padrao seguro e o que nao se pode
                  mexer.
  data_hora     -> quando foi escrito. Separado de criado_em de proposito:
                  data_hora e o dato clinico (permite registrar um
                  atendimento de ontem hoje); criado_em e quando a linha
                  entrou no banco.
  criado_em / atualizado_em -> o mesmo padrao das outras tabelas do projeto.

  O indice idx_registro_paciente_secao e OBRIGATORIO, nao e enfeite: as tres
  paginas do prontuario consulted com
      WHERE fk_paciente = ? AND secao = ? ORDER BY data_hora DESC
  e o indice composto resolve isso com uma leitura so.

       * O roteador (public/index.php) mapeia a URL para este controller:
       *   /prontuario/buscar                  -> buscar()
       *   /prontuario/dados/{idPaciente}       -> dados($idPaciente)
       *   /prontuario/secao/{idPaciente}/{secao} -> secao($idPaciente, $secao)
       *   /prontuario/salvar_dados/{id}        -> salvar_dados($id)
       *   /prontuario/registrar/{id}          -> registrar($id)
       *   /prontuario/editar_registro/{id}    -> editar_registro($id)
       *   /prontuario/salvar_registro/{id}    -> salvar_registro($id)
       *   /prontuario/finalizar_registro/{id} -> finalizar_registro($id)
       *   /prontuario/excluir_registro/{id}   -> excluir_registro($id)
       */
      class ProntuarioController {
          private $pacienteModel;
          private $registroModel;
          private $profissionalModel;

          private $telefoneModel;
          private $usuarioModel;

              Constants::PERM_PRONTUARIO_PACIENTE_ACESSAR,

          ];

          public function __construct() {

              if (!Session::has('usuario_id')) {
                  header('Location: ' . BASE_URL . '/login/index');

              }

              $this->registroModel     = new ProntuarioRegistro();

              $this->enderecoModel     = new Endereco();
              $this->telefoneModel     = new Telefone();

              $this->auditoria         = new Auditoria();
          }

          private function ehAjax(): bool {
              return strtolower($_SERVER['HTTP_X_REQUESTED_WITH'] ?? '') === 'xmlhttprequest';
          }

          private function responderJson(array $dados): void {
              header('Content-Type: application/json; charset=utf-8');
              echo json_encode($dados, JSON_UNESCAPED_UNICODE);
              exit;
          }

          /**
           * Carrega a linha de tbl_paciente e a conta como paciente logado.
           */
          private function dadosDoPaciente(int $id): array {
              $paciente = $this->pacienteModel->getById($id);
              if (!$paciente) {
                  Session::flash('error', 'Paciente nao localizado.');
                  header('Location: ' . BASE_URL . '/prontuario/buscar');
                  exit;
              }
              $usuario = $this->usuarioModel->find($paciente['fk_usuario']);
              if (!$usuario) {
                  Session::flash('error', 'Usuario do paciente nao localizado.');
                  header('Location: ' . BASE_URL . '/prontuario/buscar');
                  exit;
              }
              return [$paciente, $usuario];
          }

          private function registrarAuditoria(string $acao, string $descricao, array $props = []): void {
              $this->auditoria->registrar($acao, $descricao, $props);
          }

          /**
           * Salva o que e editavel na pagina 1: cpf, rg, sexo, estado civil,
           * telefone e endereco (com os campos que a busca de CEP preenche).
           */
          public function salvar_dados($id) {
              $id = (int)$id;
              if (!CSRF::validateRequest()) {
                  Session::flash('error', 'Token de seguranca invalido.');
                  header('Location: ' . BASE_URL . '/prontuario/dados/' . $id);
                  exit;
              }
              if (!RBAC::can(Constants::PERM_PRONTUARIO_PACIENTE_REGISTRAR)) {
                  Session::flash('error', 'Voce nao tem permissao para alterar o prontuario.');
                  header('Location: ' . BASE_URL . '/prontuario/dados/' . $id);
                  exit;
              }

              [$paciente, $usuario] = $this->dadosDoPaciente($id);

              $cpf = preg_replace('/\D/', '', (string)($_POST['cpf'] ?? ''));
              if ($cpf !== '' && strlen($cpf) !== 11) {
                  // tbl_paciente.cpf e CHAR(11). Gravar "123456" truncaria
                  // o dado e o UNIQUE nao protegeria ninguem.
                  Session::flash('error', 'O CPF deve ter 11 digitos.');
                  header('Location: ' . BASE_URL . '/prontuario/dados/' . $id);
                  exit;
              }
              if ($cpf !== '') {
                  $outro = $this->dbCpfEmUso($cpf, $id);
                  if ($outro) {
                      Session::flash('error', 'Este CPF ja pertence a outro paciente.');
                      header('Location: ' . BASE_URL . '/prontuario/dados/' . $id);
                      exit;
                  }
              }

              // As chaves planas sao as mesmas que o buscar_cep.js preenche e
              // as que Paciente::atualizar() ja sabe sincronizar.
              $this->pacienteModel->atualizar($id, [
                  'cpf'                  => $cpf !== '' ? $cpf : null,
                  'rg'                   => trim((string)($_POST['rg'] ?? '')),
                  'sexo'                 => $_POST['sexo'] ?? Constants::PACIENTE_SEXO_NAO_INFORMADO,
                  'estado_civil'         => $_POST['estado_civil'] ?? Constants::PACIENTE_ESTADO_NAO_INFORMADO,
                  'telefone_principal'   => preg_replace('/\D/', '', (string)($_POST['telefone_principal'] ?? '')),
                  'endereco_cep'         => preg_replace('/\D/', '', (string)($_POST['endereco_cep'] ?? '')),
                  'endereco_rua'         => trim((string)($_POST['endereco_rua'] ?? '')),
                  'endereco_numero'      => trim((string)($_POST['endereco_numero'] ?? '')),
                  'endereco_complemento' => trim((string)($_POST['endereco_complemento'] ?? '')),
                  'endereco_bairro'      => trim((string)($_POST['endereco_bairro'] ?? '')),
                  'endereco_cidade'      => trim((string)($_POST['endereco_cidade'] ?? '')),
                  'endereco_uf'          => strtoupper(substr((string)($_POST['endereco_uf'] ?? ''), 0, 2)),
              ]);

              $this->registrarAuditoria(
                  Constants::AUDITORIA_ACAO_EDITAR_PRONTUARIO,
                  'Atualizou os dados cadastrais do prontuario de ' . $usuario['nome'],
                  ['paciente_id' => $id]
              );

              Session::flash('success', 'Dados do paciente atualizados.');
              header('Location: ' . BASE_URL . '/prontuario/dados/' . $id);
              exit;
          }

          private function dbCpfEmUso(string $cpf, int $ignorarId): bool {
              // tbl_paciente tem UNIQUE KEY (cpf): se o mesmo CPF entrasse em
              // dois pacientes, o MySQL recusaria com o erro 1062. Checamos
              // antes para devolver uma mensagem em portugues, em vez de um
              // erro tecnico na tela.
              $db = Database::getConnection();
              $stmt = $db->prepare(
                  "SELECT id FROM tbl_paciente WHERE cpf = :cpf AND id <> :id LIMIT 1"
              );
              $stmt->execute(['cpf' => $cpf, 'id' => $ignorarId]);
              return (bool)$stmt->fetchColumn();
          }

          public function secao($id, $secao) {

                  exit;

              $registros = $this->registroModel->listarPorSecao($id, $secao);
              $contadores = $this->registroModel->contarPorSecao($id);
              $total = count($registros);

              $this->registrarAuditoria(
                  Constants::AUDITORIA_ACAO_CONSULTAR_PRONTUARIO,

              require_once __DIR__ . '/../views/prontuario/secao.php';

          /**
           * Cria um lancamento na secao pedida.
           */
          public function registrar($id) {
              $id = (int)$id;
              if (!CSRF::validateRequest()) {
                  Session::flash('error', 'Token de seguranca invalido.');
                  header('Location: ' . BASE_URL . '/prontuario/dados/' . $id);
                  exit;
              }
              if (!RBAC::can(Constants::PERM_PRONTUARIO_PACIENTE_REGISTRAR)) {
                  Session::flash('error', 'Voce nao tem permissao para registrar no prontuario.');
                  header('Location: ' . BASE_URL . '/prontuario/dados/' . $id);
                  exit;
              }

              [$paciente, $usuario] = $this->dadosDoPaciente($id);

              $secao = (string)($_POST['secao'] ?? '');
              if (!in_array($secao, $this->secoesValidas(), true)) {
                  Session::flash('error', 'Secao invalida.');
                  header('Location: ' . BASE_URL . '/prontuario/dados/' . $id);
                  exit;
              }

              $conteudo = trim((string)($_POST['conteudo'] ?? ''));
              if (mb_strlen($conteudo) < 10) {
                  Session::flash('error', 'Escreva ao menos 10 caracteres no registro.');
                  header('Location: ' . BASE_URL . '/prontuario/secao/' . $id . '/' . $secao);
                  exit;
              }

              $status = ($_POST['status'] ?? '') === Constants::PRONTUARIO_STATUS_RASCUNHO
                  ? Constants::PRONTUARIO_STATUS_RASCUNHO
                  : Constants::PRONTUARIO_STATUS_FINALIZADO;

              // >>> AUTOR x PACIENTE: cuidado aqui.
              // $usuario (acima) e o USUARIO DO PACIENTE - e ele quem e
              // passageiro da URL. O AUTOR do lancamento e quem esta
              // logado. Sao duas pessoas diferentes na maioria das vezes:
              // se voce gravar $usuario['id'] em fk_usuario, o prontuario
              // passa a dizer que o proprio paciente escreveu a evolucao.
              $autorId = (int)Session::get('usuario_id');
              if (!$autorId) {
                  Session::flash('error', 'Sessao expirada. Entre novamente.');
                  header('Location: ' . BASE_URL . '/login/index');
                  exit;
              }
              $profissionalId = $this->profissionalModel->getIdByUsuario($autorId);
              $agendamentoId = (int)($_POST['fk_agendamento'] ?? 0);

              // Data clinica opcional: por default e "agora" (o DEFAULT do
              // banco). Se o medico informar, gravamos a data do atendimento
              // - e para isso que data_hora e DATETIME e nao TIMESTAMP.
              $dataHora = null;
              $informada = trim((string)($_POST['data_hora'] ?? ''));
              if ($informada !== '') {
                  $ts = strtotime($informada);
                  if ($ts === false) {
                      Session::flash('error', 'Data do atendimento invalida.');
                      header('Location: ' . BASE_URL . '/prontuario/secao/' . $id . '/' . $secao);
                      exit;
                  }
                  $dataHora = date('Y-m-d H:i:s', $ts);
              }

              $ok = $this->registroModel->criar([
                  'fk_paciente'     => $id,
                  'fk_usuario'      => $autorId,
                  'fk_profissional' => $profissionalId ?: null,
                  'fk_agendamento'  => $agendamentoId ?: null,
                  'secao'           => $secao,
                  'conteudo'        => $conteudo,
                  'status'          => $status,
                  'data_hora'       => $dataHora,
              ]);

              if ($ok && $this->ehAjax()) {
                  $this->responderJson([
                      'success' => true,
                      'registro' => $this->registroModel->getById($this->registroModel->ultimoId()),
                      'contadores' => $this->registroModel->contarPorSecao($id),
                  ]);
              }

              if ($ok) {
                  $this->registrarAuditoria(
                      Constants::AUDITORIA_ACAO_REGISTRAR_PRONTUARIO,
                      'Registrou em ' . ProntuarioRegistro::SECOES[$secao] . ' no prontuario de ' . $usuario['nome'],
                      ['paciente_id' => $id, 'secao' => $secao, 'status' => $status]
                  );
                  Session::flash('success', $status === Constants::PRONTUARIO_STATUS_RASCUNHO
                      ? 'Rascunho salvo. Voce pode editar antes de finalizar.'
                      : 'Registro adicionado ao prontuario.');
              } else {
                  Session::flash('error', 'Nao foi possivel salvar o registro.');
              }

              header('Location: ' . BASE_URL . '/prontuario/secao/' . $id . '/' . $secao);
              exit;
          }

          private function ehMeuRascunho(array $registro, int $usuarioId): bool {
              return (int)$registro['fk_usuario'] === $usuarioId
                  && $registro['status'] === Constants::PRONTUARIO_STATUS_RASCUNHO;
          }

          public function editar_registro($idRegistro) {
              $registro = $this->registroModel->getById((int)$idRegistro);
              if (!$registro) {
                  Session::flash('error', 'Registro nao localizado.');
                  header('Location: ' . BASE_URL . '/prontuario/buscar');
                  exit;
              }
              if (!$this->ehMeuRascunho($registro, (int)Session::get('usuario_id'))) {
                  Session::flash('error', 'So o autor pode editar um rascunho.');
                  header('Location: ' . BASE_URL . '/prontuario/secao/'
                      . $registro['fk_paciente'] . '/' . $registro['secao']);
                  exit;
              }
              [$paciente, $usuario] = $this->dadosDoPaciente((int)$registro['fk_paciente']);

              require_once __DIR__ . '/../views/prontuario/editar.php';
          }

          public function salvar_registro($idRegistro) {
              if (!CSRF::validateRequest()) {
                  Session::flash('error', 'Token de seguranca invalido.');
                  header('Location: ' . BASE_URL . '/prontuario/buscar');
                  exit;
              }
              $registro = $this->registroModel->getById((int)$idRegistro);
              if (!$registro) {
                  Session::flash('error', 'Registro nao localizado.');
                  header('Location: ' . BASE_URL . '/prontuario/buscar');
                  exit;
              }
              if (!$this->ehMeuRascunho($registro, (int)Session::get('usuario_id'))) {
                  Session::flash('error', 'So o autor pode editar um rascunho.');
                  header('Location: ' . BASE_URL . '/prontuario/secao/'
                      . $registro['fk_paciente'] . '/' . $registro['secao']);
                  exit;
              }

              $conteudo = trim((string)($_POST['conteudo'] ?? ''));
              if (mb_strlen($conteudo) < 10) {

                  header('Location: ' . BASE_URL . '/prontuario/editar_registro/' . $idRegistro);
                  exit;
              }

              $this->registroModel->atualizarRascunho((int)$idRegistro, $conteudo);

              $this->registrarAuditoria(

                  'Editou um rascunho no prontuario',
                  ['registro_id' => (int)$idRegistro, 'paciente_id' => (int)$registro['fk_paciente']]

              Session::flash('success', 'Rascunho atualizado.');
              header('Location: ' . BASE_URL . '/prontuario/secao/'
                  . $registro['fk_paciente'] . '/' . $registro['secao']);
              exit;
          }

          public function finalizar_registro($idRegistro) {

  >>> ATENCAO: os rotulos das secoes vem de ProntuarioRegistro::SECOES
      (constante do MODEL, capitulo 5) - e nao de uma constante deste
      controller. Se voce escrever self::SECOES aqui, o PHP quebra com
      "Undefined constant ProntuarioController::SECOES". Por isso o codigo
      escreve sempre ProntuarioRegistro::SECOES.

  >>> LEIA: nenhum metodo deste controller confia no id da URL. Todos
      chamam dadosDoPaciente(), que carrega a linha real de tbl_paciente e
      redireciona com toast se o id nao existir. Nos metodos de rascunho
      (editar/finalizar/excluir) o id da URL e o do REGISTRO, e o codigo
      descobre o paciente a partir dele - assim nao da para editar o
      prontuario de outro paciente mudando o numero na URL.

      <?php
      class ProntuarioRegistro extends Model {
          protected $table = 'tbl_prontuario_registro';

          /**
           * Secoes do prontuario, na ordem em que aparecem as abas.
           * A chave e o valor do ENUM 'secao' no banco.
           */
          public const SECOES = [
              Constants::PRONTUARIO_SECAO_ANAMNESE     => 'Anamnese',
              Constants::PRONTUARIO_SECAO_EVOLUCAO    => 'Evolucao e Tratamento',
              Constants::PRONTUARIO_SECAO_COMPLEMENTAR => 'Informacoes Complementares',
          ];

          /**
           * Um lancamento de uma secao, do mais recente para o mais antigo.
           * Traz o nome do autor e a especialidade dele, que e o que a
           * pagina precisa mostrar em cada linha do historico.
           *
           * ATENCAO AO NOME DA COLUNA: em tbl_agendamento a coluna do fim
           * do atendimento se chama data_hora_fim. Nao existe "horario_fim"
           * em lugar nenhum do schema - se voce digitar horario_fim aqui, a
           * pagina inteira da secao quebra com
           * "Unknown column 'a.horario_fim' in 'field list'".
           */
          public function listarPorSecao($pacienteId, string $secao) {
              $stmt = $this->db->prepare(
                  "SELECT r.*,
                          u.nome AS autor_nome,
                          pr.numero_registro AS autor_registro,
                          pr.especialidade  AS autor_especialidade,
                          a.data_hora_inicio AS atendimento_inicio,
                          a.data_hora_fim    AS atendimento_fim
                     FROM {$this->table} r
                     JOIN tbl_usuario u ON u.id = r.fk_usuario
                LEFT JOIN tbl_profissional pr ON pr.id = r.fk_profissional
                LEFT JOIN tbl_agendamento a   ON a.id = r.fk_agendamento
                    WHERE r.fk_paciente = :paciente
                      AND r.secao = :secao
                 ORDER BY r.data_hora DESC, r.id DESC"
              );
              $stmt->execute(['paciente' => $pacienteId, 'secao' => $secao]);
              return $stmt->fetchAll(PDO::FETCH_ASSOC);
          }

          /**
           * Quantos registros existem em cada secao (para os badges das abas).
           * Uma consulta so, em vez de tres.
           */
          public function contarPorSecao($pacienteId): array {
              $stmt = $this->db->prepare(
                  "SELECT secao, COUNT(*) AS total
                     FROM {$this->table}
                    WHERE fk_paciente = :paciente
                 GROUP BY secao"
              );
              $stmt->execute(['paciente' => $pacienteId]);

              $contadores = array_fill_keys(array_keys(self::SECOES), 0);
              foreach ($stmt->fetchAll(PDO::FETCH_ASSOC) as $linha) {
                  if (isset($contadores[$linha['secao']])) {
                      $contadores[$linha['secao']] = (int)$linha['total'];
                  }
              }
              return $contadores;
          }

          public function getById($id) {
              $stmt = $this->db->prepare(
                  "SELECT * FROM {$this->table} WHERE id = :id LIMIT 1"
              );
              $stmt->execute(['id' => $id]);
              return $stmt->fetch(PDO::FETCH_ASSOC) ?: null;
          }

          public function ultimoId(): int {
              return (int)$this->db->lastInsertId();
          }

          public function criar(array $dados): bool {
              // data_hora e opcional: quando o controller nao manda, o
              // DEFAULT CURRENT_TIMESTAMP do banco entra no lugar. Nunca
              // mande string vazia aqui, senao o MySQL complains.
              $colunas = '(fk_paciente, fk_usuario, fk_profissional, fk_agendamento,
                       secao, conteudo, status)';
              $valores = '(:fk_paciente, :fk_usuario, :fk_profissional, :fk_agendamento,
                       :secao, :conteudo, :status)';
              $params = [
                  'fk_paciente'     => $dados['fk_paciente'],
                  'fk_usuario'      => $dados['fk_usuario'],
                  'fk_profissional' => $dados['fk_profissional'] ?: null,
                  'fk_agendamento'  => $dados['fk_agendamento'] ?: null,
                  'secao'           => $dados['secao'],
                  'conteudo'        => $dados['conteudo'],
                  'status'          => $dados['status'],
              ];
              if (!empty($dados['data_hora'])) {
                  $colunas = str_replace('status)', 'status, data_hora)', $colunas);
                  $valores = str_replace(':status)', ':status, :data_hora)', $valores);
                  $params['data_hora'] = $dados['data_hora'];
              }
              $stmt = $this->db->prepare(
                  "INSERT INTO {$this->table} {$colunas} VALUES {$valores}"
              );
              return $stmt->execute($params);
          }

          /**
           * Edita APENAS rascunho. O WHERE com status = 'rascunho' e a
           * protecao: mesmo que o controller erre a checagem, o banco
           * recusa a alteracao de um registro finalizado.
           */
          public function atualizarRascunho($id, string $conteudo): bool {
              $stmt = $this->db->prepare(
                  "UPDATE {$this->table}
                      SET conteudo = :conteudo
                    WHERE id = :id
                      AND status = 'rascunho'"
              );
              return $stmt->execute(['conteudo' => $conteudo, 'id' => $id]);
          }

          public function finalizar($id): bool {
              $stmt = $this->db->prepare(
                  "UPDATE {$this->table}
                      SET status = 'finalizado'
                    WHERE id = :id
                      AND status = 'rascunho'"
              );
              return $stmt->execute(['id' => $id]);
          }

          /**
           * Apaga APENAS rascunho. Registro finalizado e intocavel - para
           * corrigir, o medico cria outro.
           */
          public function excluir($id): bool {
              $stmt = $this->db->prepare(
                  "DELETE FROM {$this->table}
                    WHERE id = :id
                      AND status = 'rascunho'"
              );
              return $stmt->execute(['id' => $id]);
          }

          /**
           * Historico completo do paciente, todas as secoes (usado no PDF e
           * para mostrar a linha do tempo).
           */
          public function timeline($pacienteId, $limite = 200) {
              $stmt = $this->db->prepare(
                  "SELECT r.*, u.nome AS autor_nome, pr.especialidade AS autor_especialidade
                     FROM {$this->table} r
                     JOIN tbl_usuario u ON u.id = r.fk_usuario
                LEFT JOIN tbl_profissional pr ON pr.id = r.fk_profissional
                    WHERE r.fk_paciente = :paciente
                 ORDER BY r.data_hora DESC, r.id DESC
                    LIMIT :limite"
              );
              $stmt->bindValue(':paciente', $pacienteId, PDO::PARAM_INT);
              $stmt->bindValue(':limite', (int)$limite, PDO::PARAM_INT);
              $stmt->execute();
              return $stmt->fetchAll(PDO::FETCH_ASSOC);
          }
      }

      function showToast(tipo, mensagem, duracao = 3000) {
